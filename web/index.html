Setup

  1. Keep Bay Control running on the sim PC.
  2. Phone/tablet must be on the same Wi‑Fi (not Guest).
  3. Focus GSPro or Pureplay so controls are armed.
  4. Share → Add to Home Screen to bookmark this pairing.

If taps do nothing, the status chip usually explains why (sim not focused, paused, or offline).
